# 🍽️ Zomato Exploratory Data Analysis (EDA) Using Python

A complete Exploratory Data Analysis (EDA) project on Zomato restaurant data using Python. This project focuses on analyzing restaurant trends, customer preferences, online delivery patterns, ratings, pricing insights, and location-based restaurant performance.

The project demonstrates data cleaning, visualization, feature analysis, and business insight generation using Python libraries.

---

# 📌 Project Overview

The objective of this project is to explore and analyze Zomato restaurant data to uncover useful insights that can help understand:

* Customer dining preferences
* Restaurant performance
* Popular cuisines
* Online delivery trends
* Restaurant ratings
* Cost distribution
* Location-based food trends

This project simulates real-world food delivery and restaurant analytics.

# 📂 Dataset Information

The dataset contains restaurant-related information from Zomato.

## Main Columns

| Column Name          | Description                  |
| -------------------- | ---------------------------- |
| Restaurant Name      | Name of the restaurant       |
| Country Code         | Country identifier           |
| City                 | Restaurant city              |
| Address              | Restaurant address           |
| Locality             | Restaurant locality          |
| Cuisines             | Types of cuisines offered    |
| Average Cost for Two | Approximate dining cost      |
| Currency             | Currency type                |
| Has Table Booking    | Booking availability         |
| Has Online Delivery  | Online delivery availability |
| Aggregate Rating     | Restaurant rating            |
| Rating Color         | Rating category color        |
| Votes                | Number of customer votes     |
| Price Range          | Restaurant pricing category  |
